# Ultimate Motherload

## Download / How to Play

1. Download the latest version of `Ultimate_Motherload.swf` from this GitHub repository.
2. Open the `.swf` file using a Flash player such as [Ruffle](https://ruffle.rs/).
3. Play Ultimate Motherload!

## About

This mod is build on top of the Motherload_SRE mod, built by Speedox12. It adds a new zoomed out view, new items from each shop category, a new phase to the bossfight, cheats, and many QOL changes:

## New Items

### Drills
- **Plasma Drill** - Drill much faster, and drill through rock at 0.5x speed.
- **Atomic Drill** - Drill with constant explosions. Works in the air with directional explosives (down ↓ , down-side ↓ → , and sideways ↓ ↑ → ).

### Hulls
- **Deflector Hull** - 5x HP of Energy Shielded Hull, changes character appearance to be light grey.
- **Anti Matter Hull** - Invulnerable, very overpowered.

### Engines
- **V24 Panther Engine** - Much more powerful.
- **V32 Atomic Engine** - Even more powerful and leaves behind explosive particles.

### Fuel
- **Quantum Compression Tank** - 2x fuel compared with liquid compression tank, makes you fall 50% faster.
- **Zero Point Fuel Core** - Unlimited fuel, makes you fall 100% faster.

### Radiators
- **Thermal Nullifier** - Blocks all damage from drilling lava, reduces gas pocket damage by 95%, all other damage reductions the same as the Tri Turbine Freon Array
- **Magma Inversion Array** - Same as Thermal Nullifier, but heals you as you drill through lava.

### Cargo
- **Dimensional Storage** - 2x storage compared to Leviathan Bay.
- **Zero-Point Storage** - Infinite storage, instantly sells minerals as you mine them.

### Explosives
- **Fusion Charge** - Bigger explosion than C4.
- **Singularity Charge** - Much bigger explosion than C4.

## New Bossfight Phase

The new phase has 3 special attacks. Fire breath, claw, and laser. Claw and laser each have a boosted version when the boss is on low HP.

## Cheats

- **No Earthquakes** - Removes all chance of earthquakes.
- **Only Good Seeds** - Searches seeds until certain conditions are met, mainly that a relic will spawn on the left half of the map and above 1200ft.
- **Relic Detector** - Shows at the surface a depth marker for early relics. Also shows a number over the three columns to the right of the fuel station, representing the percentage of air that is within the first 1000ft of that column, so typically you choose the highest one to start your dig.
- **Amazonite Detector** - Shows at the surface a depth marker for early amazonite.
- **Speedrun Path** - Activated by purchasing the ruby drill and going back down your path. It will calculate an optimal speedrun route, as seen in the "Computer Optimized Motherload" video. Good for practicing.
- **Explosives Path** - Calculates a path with explosives through the final section to the boss. This algorithm has been approximated from the video so it runs better, however is a bit less accurate and you can probably be just as fast without this cheat.

## QOL Changes

- Zoom in and out with the `[]` keys.
- Popups now disappear by pressing any arrow key.
- Map generation for random seed is altered to use a specified seed, allowing replay of that seed. Previously, random seed map generation used random values as it went along, rather than first using a random seed, then basing the generation off that. This change shouldn't create any statistical difference between the kind of map generated.
- Map seed is displayed in options menu, and after death, allow you to retry that specific map.
- A configurable split timer is added to the options menu for speedrunning.
- Various small performance enhancements, mostly to run the zoomed out mode without lag.
